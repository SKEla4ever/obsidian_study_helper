# Assignment 01 · Compare diagnostic plots

## Q01

查看 [[Courses/DEMO101/Labs/variance/Lab|Variance lab]] 的静态图或交互图。分别比较较小和较大的 fitted values 区域。描述 residuals 的垂直散布随参数变化的方向。

知识点 · [[Courses/DEMO101/Modules/01-Linear-Regression/03-Constant-Variance|Constant variance]]

> [!success]- Solution
> 在参数为零时，生成数据使用相同的 error spread。随着参数增大，较大的 predictor values 对应更大的 error spread。Residual plot 通常在较大的 fitted values 一侧更宽。有限样本中的局部波动仍会存在。
