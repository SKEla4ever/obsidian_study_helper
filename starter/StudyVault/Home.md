## Try the example

1. Open the DEMO101 course and go to **Linear regression assumptions → Constant variance**. Hover over a concept link in Reading view to preview the definition.
2. Open **Worksheet 01 · Q02** from the concept note and expand **Solution**. The course's **Practice** page lists questions marked for review.
3. Open **Variance lab** for the interactive plots and instructions for running them offline.

## Add a course

Copy this vault to your personal study folder. In the copy, duplicate `Blueprints/Blank-Course` into `Courses` and rename the new folder with your course ID, such as `STA302-2026F`. Open its `Course.md`, fill in the course details, and add a link below **Courses**.

With Python 3, you can generate the same folder from a terminal in the vault:

```bash
python3 Tools/new_course.py STA302-2026F --title "Regression Analysis"
```

Paste the link it prints below **Courses**. Start by adding one module, one source, and one worksheet.
